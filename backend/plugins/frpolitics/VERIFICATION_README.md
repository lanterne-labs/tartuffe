# Party Fact Verification for frpolitics Plugin

This directory contains a comprehensive test-based verification system to ensure that party facts generated by the frpolitics plugin accurately reflect the actual voting patterns of affiliated deputies.

## Quick Start

### 1. Run Verification Tests

```bash
# Run all verification tests
cd backend/plugins/frpolitics
make -f Makefile.tests test-verification

# Run end-to-end tests (requires DATABASE_URL)
make -f Makefile.tests test-e2e
```

### 2. Run Demo with Mock Data

```bash
# Run demonstration with mock data
cd backend/plugins/frpolitics
go run -v -run TestPartyFactAccuracyWithMockData
```

## What the Verification System Does

### 1. **Party Fact Accuracy Verification**
- Compares party facts against actual deputy voting patterns
- Detects when party facts don't match majority positions
- Provides detailed discrepancy reports
- Calculates consistency scores (0-100%)

### 2. **Deputy-Party Consistency Checking**
- Ensures deputy votes align with their affiliated party positions
- Identifies temporal affiliation issues
- Tracks discrepancies between individual and party positions

### 3. **Temporal Affiliation Validation**
- Validates deputy-party relationships are correctly established
- Checks time boundaries and attribution completeness
- Ensures affiliations are valid at vote time

## Key Files

- `party_fact_verification_test.go`: Core verification logic and unit tests
- `e2e_verification_test.go`: End-to-end integration tests
- `TESTING_VERIFICATION.md`: Comprehensive testing documentation
- `Makefile.tests`: Easy-to-use test targets

## Usage Examples

The verification system will output detailed reports showing:

- **Total Party Facts**: Number of party facts generated
- **Accurate Party Facts**: Number that correctly represent voting patterns
- **Inaccurate Party Facts**: Discrepancies with detailed explanations
- **Consistency Score**: Percentage of accurate party facts

## Quality Thresholds

- **✅ Good**: ≥80% consistency for real data
- **⚠️ Moderate**: 60-79% consistency
- **❌ Poor**: <60% consistency

This verification system ensures that the frpolitics plugin generates reliable party facts that truly represent the voting behavior of French deputies and their affiliated parties.
